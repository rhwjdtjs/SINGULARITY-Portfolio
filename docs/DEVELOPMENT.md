# 현재 개발 현황

**2026년 9월 20일 확인 기준입니다.** 공개 소개에서 제작 목표와 실제 반영 상태를 혼동하지 않도록 구분합니다. 비공개 개발 저장소의 변경 기록을 공개 가능한 기능 설명으로 요약했습니다.

## 상태를 읽는 방법

| 상태 | 의미 |
| --- | --- |
| 기존 통합 기록 | 팀의 이전 구현·통합 결과를 기록합니다. 현재 출시판 전체의 검증 결과는 아닙니다. |
| 개발 브랜치 반영 | 검토한 변경을 팀 개발본에 합쳤습니다. 배포 검수가 끝났다는 뜻은 아닙니다. |
| 검토 중 | 구현자가 변경을 제출했으며, 아직 팀 개발본에 합치지 않았습니다. |
| 제작·통합 예정 | 앞으로 제작하거나 다른 기능과 연결해 검사해야 합니다. |

## 확인한 변경

| 기능 | 상태 | 확인 범위 |
| --- | --- | --- |
| 플레이어·바디캠·권총·열쇠와 문·적 AI | 기존 통합 기록 | [MVP1 기록](MVP1-2026-09-09.md)에 당시 팀 통합 결과를 정리했습니다. |
| 적의 청각 감지 | 개발 브랜치 반영 | 솔마님의 「AI Perception (Hearing) 추가」 변경에서 소리를 감지하고 해당 위치를 조사하는 기반을 확인했습니다. |
| 탄약 아이템과 무기 상태 표시 | 검토 중 | 푸우님의 「puu m2 01 PR」 설명에 권총·샷건 탄약 데이터와 권총 예비 탄약·화면 갱신이 포함됩니다. |
| 소비 아이템과 상태 효과 | 검토 중 | 같은 변경에 효과 시작·종료, 재적용과 시간 종료 처리 기반이 포함됩니다. |
| 아이템 외곽선과 열쇠 부족 안내 | 검토 중 | 같은 변경에 바라보는 대상의 외곽선 켜기·끄기와 열쇠가 없을 때의 안내가 포함됩니다. |

검토 중인 항목은 제출된 변경 설명을 기준으로 합니다. 이 문서를 작성하며 해당 기능의 인게임 동작이나 배포 빌드를 새로 검증한 것은 아닙니다. 변경 제출, 개발본 반영, 실제 플레이 검사를 서로 구분합니다.

## 다음 제작 범위

| 영역 | 후속 작업 |
| --- | --- |
| 플레이어와 무기 | 은신과 조작 복구, 샷건 전체 동작, 무기를 든 자세와 상호작용 애니메이션을 연결합니다. |
| 적 | 총을 사용하지 않는 두 적의 행동, 벽·천장 이동과 관찰 정보에 한정한 학습을 제작·검사합니다. |
| 퍼즐과 이야기 | 퍼즐 공통 기반을 별도로 만들고, 개별 퍼즐과 문서 읽기 화면을 연결합니다. |
| 전체 진행 | 5층 공간, 자원 관리와 진행 상태,저장·복원 및 주요 진행 경로를 통합합니다. |
| 배포 | 설정·조작 안내, 기본 효과음, 반복 플레이와 성능 검사를 진행합니다. |

구현 상세 코드, 내부 문서 주소, 에셋 원본 경로와 개인 작업 가이드는 공개하지 않습니다. 개발 사례는 담당자와 구현 의도, 확인한 결과를 중심으로 갱신합니다.
