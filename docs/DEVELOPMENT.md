## 검사 범위와 다음 작업

문·상자 조작에는 Editor·Game Development 빌드와 자동 검사 기록이 있습니다. 시험용 외부 결과 연결을 포함한 기능 검사이며 최종 애니메이션을 연결한 직접 플레이 확인은 남아 있습니다. 침식·주사 사용에는 병합 전 PIE에서 입력을 주입해 검사한 기록이 있습니다. 최신 병합본의 직접 키보드·마우스 조작과 최종 연출 확인은 별도로 진행해야 합니다.

현재 탄약 아이템을 새 총기 상태에 반영하는 연결과 퍼즐의 진입·선행 조건 검사에서 후속 수정이 필요합니다. 퍼즐 전체와 탄약 획득 흐름을 통합 검수 완료로 표시하지 않습니다.

저장·불러오기, 5층의 필수 진행, 개별 퍼즐과 문서 읽기, 두 적의 근접 공격·은신 수색·벽과 천장 이동을 이어서 제작·통합합니다. 그래픽·카메라 설정, 조작 안내와 기본 효과음도 실제 배포용 실행 파일에서 확인할 예정입니다.
