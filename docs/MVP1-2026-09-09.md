# MVP1 완료 및 통합 테스트 기록

**2026년 9월 9일, MVP1의 기본 플레이 루프를 통합하고 팀 통합 테스트를 완료했습니다.** 플레이어 조작과 바디캠, 권총 전투, 적 AI, 체력 HUD, 열쇠 획득과 문 상호작용을 프로토타입에 연결했습니다.

> 이 문서는 당시 프로토타입의 기록입니다. 현재 게임 방향에서는 적의 총기 사용을 제외합니다. 당시의 적 총격·무기 드롭은 현재 제작 목표를 뜻하지 않습니다. 최신 방향은 [게임 소개](GAMEPLAY.md)와 [개발 현황](DEVELOPMENT.md)에서 확인합니다.

이번 단계의 성과는 개별 담당자가 구현한 기능을 하나의 플레이 흐름으로 연결한 것입니다. 공개 플레이 빌드는 아직 제공하지 않으며, 이후 MVP2에서 저장과 진행 복원, 추가 무기, 문 손동작과 화면 안내를 확장합니다.

## 후속 확인과 MVP2 연결

통합 전 코드리뷰에서 제기한 아래 경계 조건은 개별 수정·재검증 결과를 별도로 기록해야 합니다. 최종 통합 완료 기록만으로 각각 해결됐다고 판정하지 않습니다.

- AI가 피격 중 시야를 잃거나 타깃이 사라졌을 때, 피격 종료 후 적절한 행동으로 복귀하는지 확인합니다.
- 사망 몽타주가 없거나 재생에 실패할 때 충돌이 통로를 막지 않는지 확인합니다.

후속 작업은 2026년 9월 17일 이후의 새 제작 방향으로 진행합니다. 은신, 무기와 동작, 두 적의 감지, 퍼즐과 문서 읽기 기반을 먼저 연결하고, 전체 공간과 저장·진행 복원으로 확장합니다. 최신 목표는 [제작 일정](ROADMAP.md)을 따릅니다.
