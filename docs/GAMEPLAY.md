# SINGULARITY 게임 소개

**문서를 읽고 길을 열며, 제한된 자원으로 살아남는 1인칭 병원 생존 공포 게임을 제작합니다.** 아래 내용은 제작 방향입니다. 실제 반영 상태는 [개발 현황](DEVELOPMENT.md)에서 확인합니다.

## 병원 안에서 이어지는 탐색

병원은 총 5층으로 구성합니다. 1·2층에서는 접수 공간을 포함한 병원 시설을 탐색하고, 진행에 따라 3·4·5층 병동으로 이동합니다. 초반에는 공간과 조작을 익히고, 이후 적의 위협을 단계적으로 만나도록 설계합니다.

플레이어는 신경 침식 증상을 억제하기 위해 약과 주사를 구해야 합니다. 새로운 방에 들어갈 방법을 찾는 동안 필요한 물품과 안전한 경로를 함께 살핍니다. 상세한 인물 설정, 이야기의 반전과 결말은 플레이에서 확인하도록 남겨둡니다.

## 문서와 물건이 주는 단서

문서와 상호작용하면 읽기 화면이 열리고, 병원의 배경과 진행 단서를 텍스트로 확인합니다. 긴 대사나 시네마틱보다 플레이어가 직접 관찰하고 연결하는 경험을 중심으로 구성합니다.

| 퍼즐에서 하는 행동 | 플레이 경험 |
| --- | --- |
| 문서와 물건의 표시를 대조합니다. | 서로 떨어져 있는 단서를 연결합니다. |
| 물건을 회전시켜 관찰합니다. | 처음에는 보이지 않던 면에서 정보를 찾습니다. |
| 아이템을 사용하거나 합성합니다. | 확보한 물품으로 막힌 장치를 작동시킵니다. |
| 물건을 밀거나 무게·배관·전력을 조절합니다. | 공간의 상태를 바꾸어 새로운 길을 엽니다. |

표는 제작할 상호작용의 유형을 설명합니다. 특정 퍼즐의 위치, 정답과 보상 순서는 공개하지 않습니다.

## 두 적과 공정한 추적

적은 총을 사용하지 않습니다. 서서 이동하는 모습과 바닥·벽·천장을 기어다니는 움직임으로 공간의 위협을 만듭니다. 플레이어는 침대나 책상 아래에 숨거나 다른 길로 돌아갈 수 있습니다.

감지는 시야와 청각을 기준으로 합니다. 플레이어를 놓치면 마지막으로 확인한 위치나 소리가 난 장소를 조사하도록 제작합니다. 이후 행동 학습도 적이 실제로 관찰한 이동과 은신 정보에 한정합니다. 멀리 떨어져 보이지도 들리지도 않는 플레이어의 현재 위치를 항상 알아내는 방식으로 설계하지 않습니다.

청각 감지 기반은 개발 브랜치에 반영했습니다. 두 적의 전체 행동, 표면 이동과 학습은 후속 제작·검사 대상입니다.

## 부족한 탄약으로 선택하는 대응

처음부터 무기를 가지고 시작하지 않습니다. 탐색과 퍼즐 진행으로 권총과 샷건을 확보하도록 계획합니다. 사격은 위협을 물러나게 하고 이동할 시간을 확보하는 선택입니다.

화면 중앙 조준점과 정밀 조준 확대를 사용하지 않고, 총을 살짝 들어 총구 방향으로 쏘는 감각을 목표로 합니다. 무기 자세, 사격·장전 동작과 탄약 표시를 함께 연결합니다. 샷건용 탄약 데이터가 있다는 사실만으로 샷건 전체 동작이 완성된 것으로 표시하지 않습니다.

## 읽을 수 있는 공포

바디캠 시점과 제한된 시야를 활용하면서도 필요한 단서와 상호작용 대상은 알아볼 수 있도록 제작합니다. 적 접근, 총성, 문과 주사 사용 등의 기본 효과음은 행동을 판단하는 신호로 유지합니다.

카메라 흔들림과 화면 효과의 조절, 화면 설정과 조작 안내도 배포 전 확인 대상입니다. 실제 품질과 성능은 배포 빌드에서 측정한 뒤 공개합니다.
