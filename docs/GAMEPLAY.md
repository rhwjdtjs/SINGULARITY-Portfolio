# SINGULARITY 게임 소개

플레이어는 AI가 통제하는 폐병원을 탐험하며 치료제를 찾습니다. 병동에서 연구실과 지하 터미널로 이어지는 공간을 관찰하고, 적의 위협 속에서 이동과 자원 사용을 결정합니다.

## 플레이 흐름

1. 공간의 소리와 시야를 확인하고 안전한 탐색 경로를 선택합니다.
2. 단서와 상호작용 대상을 찾아 현재 목표를 파악합니다.
3. 환경 퍼즐을 해결하여 새로운 이동 경로를 확보합니다.
4. 위협이 접근하면 은신, 우회 또는 제한적인 전투를 선택합니다.
5. 진행 상태를 보존하고 다음 구역으로 이동합니다.

이 흐름은 제작 목표입니다. 최종 플레이 경험은 실제 테스트 결과에 따라 조정합니다.

## 생존과 추적

제한된 탄약은 교전 선택에 무게를 부여합니다. 권총과 산탄총은 상황별 대응 수단으로 설계하며, 사격 소음과 이동 행동이 위협의 반응으로 연결되도록 제작합니다. 적의 탐지와 추격은 플레이어가 원인과 결과를 이해할 수 있는 시청각 신호를 갖추도록 합니다.

## 바디캠과 공포 연출

내부 렌더 해상도는 100%를 기준으로 두고, 렌즈 주변부의 부드러움과 제한적인 색수차, 이동에 반응하는 카메라를 통해 장비로 촬영한 질감을 만듭니다. 어둠 속에서도 진행에 필요한 형태와 단서는 읽을 수 있어야 합니다. 공포는 시야의 제한, 공간 음향, 위협의 예고와 긴장 해소의 리듬으로 설계합니다.

카메라 흔들림과 시각 효과에는 멀미를 줄일 수 있는 조절 경로를 마련합니다. 실제 품질과 성능은 배포 빌드에서 확인한 결과를 공개합니다.

## 공개 자료의 범위

게임플레이 소개는 초반 경험을 중심으로 제공합니다. 핵심 반전, 결말과 퍼즐 정답은 공개 소개에 포함하지 않습니다. 개발 사례는 문제, 구현 의도, 검증 방법과 결과를 중심으로 설명합니다.
