최종 애니메이션과 전체 공간은 제작·연결 중입니다. 개별 기능의 빌드나 PIE 검사 기록을 공개 버전의 배포 검수로 대신하지 않습니다.

## 공개 목표

데모는 2026년 11월 30일–12월 7일, 정식 출시는 2027년 1–6월을 목표로 합니다. 검수가 끝나면 이 문서와 GitHub Releases에 실제 다운로드 및 버전 정보를 추가합니다. [제작 일정](ROADMAP.md)을 함께 확인해 주세요.

각 배포에는 공개일, 지원 환경, 변경 내용, 알려진 문제와 저장 데이터 호환 여부를 기록합니다. 성능 결과에는 측정 장비·해상도·그래픽 설정·테스트 구간을, 화면 자료에는 촬영 버전을 표시합니다.

공개 빌드의 문제를 제보할 때에는 Issues에 버전, 발생 위치, 재현 순서와 기대한 동작을 적어 주세요. 개인 정보가 들어간 화면이나 로그는 제외해 주세요.
