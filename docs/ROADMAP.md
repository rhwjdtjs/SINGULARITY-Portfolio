# 제작 일정

2026년 10월 1일 확인 기준입니다. 최신 제작 계획은 5층 병원에서 탐색·문서·퍼즐·생존을 연결하는 방향입니다. 아래 날짜는 목표이며 실제 반영한 기능은 [개발 현황](DEVELOPMENT.md)에 따로 기록합니다.

| 단계 | 목표 시기 | 내용 |
| --- | --- | --- |
| MVP1 기본 플레이 흐름 | 2026년 9월 9일 통합 기록 | 플레이어, 권총, 적 AI, 열쇠·문과 HUD를 연결했습니다. [당시 결과](MVP1-2026-09-09.md)를 확인합니다. |
| MVP2 기능 제작과 연결 | 2026년 9월–10월 초, 진행 중 | 공통 조작·은신·권총과 샷건·문과 상자 조작·침식과 주사 사용을 개발본에 반영했습니다. 실제 배치와 팀원 기능의 연결을 진행합니다. |
| 전체 기능과 공간 통합 | 2026년 11월 7일까지 목표 | 5층 진행, 두 적, 퍼즐·문서, 저장과 주요 진행 흐름을 연결합니다. |
| 반복 검사와 데모 후보 | 2026년 11월 8일 이후 | 진행 차단, 저장 오류, 충돌과 성능을 점검하고 배포 후보를 만듭니다. |
| 데모 공개 | 2026년 11월 30일–12월 7일 목표 | 검수를 마친 실행 파일과 안내, 알려진 문제를 공개합니다. |
| 정식판 개선과 출시 | 2027년 1–6월 목표 | 데모 의견을 반영하고 콘텐츠·저장 호환성·성능·배포 상태를 확인합니다. |

데모는 초반 구역을 공개하는 별도 단계입니다. 현재 공개 빌드는 없으며 확정 출시일은 검수 결과에 따라 안내합니다.

## 배포 전 확인

진행 차단, 저장 데이터 손실, 반복 충돌과 조작 복구 오류가 남은 후보는 배포 완료로 표시하지 않습니다. 주요 진행 경로, 입력과 화면, 저장·불러오기는 실제 배포용 실행 파일에서 확인합니다.

공개 버전에는 실행 조건, 변경 내용과 알려진 문제를 함께 기록하고 배포 페이지에서 내려받은 파일의 설치·실행까지 검사합니다. 내부 담당자별 마감과 상세 작업 순서는 이 공개 일정에 포함하지 않습니다.
