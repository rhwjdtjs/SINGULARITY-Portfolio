## 공개 판단 기준

진행을 막는 결함, 저장 데이터 손상과 반복 충돌이 남아 있는 빌드는 정식 배포 대상으로 표시하지 않습니다. 입력, UI, 저장과 불러오기, 주요 진행 경로를 패키징한 실행 파일에서 확인합니다. 공개한 빌드에는 버전, 변경 내용, 알려진 문제와 실행 조건을 함께 기록합니다.
