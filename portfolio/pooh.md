# 푸우 제작 담당

푸우는 상호작용, 퍼즐, 목표, HUD, 옵션과 자막 및 시네마틱을 담당합니다. 플레이어가 공간의 단서를 읽고 현재 목표를 이해하며 진행할 수 있도록 기능과 화면을 연결합니다.

## 개발 사례의 검증 범위

상호작용 사례에서는 대상 선택, 사용 가능 조건과 입력 피드백을 설명합니다. 퍼즐 사례에서는 진행 조건, 중복 입력과 저장 후 복원을 검증합니다. HUD와 목표 사례에는 화면 해상도와 입력 환경을 기록합니다. 스토리 연출 사례는 공개 가능한 범위의 카메라, 자막, 음향과 조작 복귀를 설명하고 공동 제작 부분을 구분합니다.

## 공개 구현 기록

### MVP1 · 2026년 9월 9일 완료

체력 HUD, 상호작용 대상 감지와 안내, 문 열기·닫기를 구현했습니다. 인벤토리와 키 아이템 획득, 문의 열쇠 조건, 잠김 안내 및 감지 아웃라인을 추가하고 메샤미의 플레이어·통합 레벨에 연결했습니다. 기본 열쇠는 문을 연 뒤에도 소지 상태를 유지합니다.

통합 전 열쇠·문 변경의 UE 5.5 Development Editor 빌드 통과를 확인했으며, 최종 기능은 팀 MVP1 통합에 반영했습니다. [검증 범위와 통합 기록](../docs/MVP1-2026-09-09.md)을 확인하실 수 있습니다. 키 획득 안내·소지 표시와 대표 문 손동작 연결은 MVP2에서 확장합니다.
