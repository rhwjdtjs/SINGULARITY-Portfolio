# 푸우 개발 기록

아이템·상호작용, 퍼즐 기반과 개별 퍼즐, 문서 읽기·안내·설정 화면을 담당합니다. 확인 기준은 2026년 10월 1일입니다.

## MVP1 · 2026년 9월 9일

체력 HUD, 상호작용 대상 감지와 안내, 문 열기·닫기를 구현했습니다. 인벤토리와 키 아이템 획득, 문의 열쇠 조건, 잠김 안내와 감지 아웃라인을 추가하고 메샤미의 플레이어·통합 레벨에 연결했습니다. 기본 열쇠는 문을 연 뒤에도 소지 상태를 유지합니다.

통합 전 열쇠·문 변경의 UE 5.5 Development Editor 빌드 통과와 최종 MVP1 반영을 확인했습니다. [당시 검증 범위와 통합 기록](../docs/MVP1-2026-09-09.md)을 따릅니다.

## MVP2 · 팀 개발본 반영

2026년 9월 20일, 탄약 데이터와 화면 상태 갱신, 소비 아이템과 상태 효과, 외곽선·열쇠 부족 안내 개선을 반영했습니다. 상태 효과에는 시작·종료, 재적용과 시간 종료 처리가 포함됩니다.

9월 30일에는 구역 진입 퍼즐, 요구 아이템 검사, 완료 기록과 알림을 반영했습니다. 재료 부족 시 재시도와 완료 후 반복 요청을 검사한 기록이 있습니다. 몸 진입·선행 조건·조작 제한과 완료 후 상호작용 가능 상태는 후속 수정이 필요합니다.

이 기록은 구역 진입 중심의 기반 구현입니다. 전체 퍼즐 조건이나 개별 퍼즐·보상·저장 연결이 완성된 단계로 표시하지 않습니다.

## 후속 연결

아이템 사용·합성, 문서 읽기와 개별 퍼즐, 목표 안내·설정 화면을 확장합니다. 탄약 획득은 메샤미의 새 총기 예비탄에 연결하고 퍼즐 완료 결과는 문·상자의 해금과 이어서 검사해야 합니다. 주사 사용과 수량 처리는 메샤미의 투약 기능과 함께 연결합니다.

저장 파일 작성은 메샤미 담당이며 퍼즐과 화면에서 필요한 진행 상태의 전달·복원은 담당자 간 연결 범위로 구분합니다.
