# 푸우 제작 담당

푸우는 상호작용, 퍼즐, 목표, HUD, 옵션과 자막 및 시네마틱을 담당합니다. 플레이어가 공간의 단서를 읽고 현재 목표를 이해하며 진행할 수 있도록 기능과 화면을 연결합니다.

## 개발 사례의 검증 범위

상호작용 사례에서는 대상 선택, 사용 가능 조건과 입력 피드백을 설명합니다. 퍼즐 사례에서는 진행 조건, 중복 입력과 저장 후 복원을 검증합니다. HUD와 목표 사례에는 화면 해상도와 입력 환경을 기록합니다. 스토리 연출 사례는 공개 가능한 범위의 카메라, 자막, 음향과 조작 복귀를 설명하고 공동 제작 부분을 구분합니다.

## 공개 구현 기록

현재 이 페이지는 제작 담당 범위를 안내합니다. 검증한 빌드의 영상과 본인 기여를 연결한 구현 사례는 이후 등록합니다.
