# 푸우님 제작 담당

푸우님는 아이템과 상호작용, 퍼즐 공통 기반과 개별 퍼즐, 문서 읽기·안내·설정 화면을 담당합니다. 플레이어가 공간의 단서를 읽고 현재 목표를 이해하며 진행할 수 있도록 기능과 화면을 연결합니다.

## 개발 사례의 검증 범위

상호작용 사례에서는 대상 선택, 사용 가능 조건과 입력 피드백을 설명합니다. 퍼즐 사례에서는 진행 조건, 중복 입력과 저장 후 복원을 검증합니다. HUD와 목표 사례에는 화면 해상도와 입력 환경을 기록합니다. 문서 읽기 사례에서는 읽기 화면을 열고 닫을 때 조작과 안내가 올바르게 복구되는지 확인합니다.

## 공개 구현 기록

### MVP1 · 2026년 9월 9일 완료

체력 HUD, 상호작용 대상 감지와 안내, 문 열기·닫기를 구현했습니다. 인벤토리와 키 아이템 획득, 문의 열쇠 조건, 잠김 안내 및 감지 아웃라인을 추가하고 메샤미의 플레이어·통합 레벨에 연결했습니다. 기본 열쇠는 문을 연 뒤에도 소지 상태를 유지합니다.

통합 전 열쇠·문 변경의 UE 5.5 Development Editor 빌드 통과를 확인했으며, 최종 기능은 팀 MVP1 통합에 반영했습니다. [검증 범위와 통합 기록](../docs/MVP1-2026-09-09.md)을 확인하실 수 있습니다. 키 획득 안내·소지 표시와 대표 문 손동작 연결은 MVP2에서 확장합니다.

## 아이템과 화면 개선 · 검토 중

2026년 9월 20일 확인 기준, 「puu m2 01 PR」은 제출되었으며 아직 개발본에 병합되지 않았습니다. 제출 설명에 포함된 범위는 다음과 같습니다.

- 권총·샷건 탄약 데이터와 권총 예비 탄약·무기 상태 표시 갱신을 추가합니다.
- 소비 아이템과 상태 효과의 시작·종료, 재적용과 시간 종료 처리 기반을 추가합니다.
- 열쇠가 부족할 때 안내를 표시하고, 바라보는 아이템의 외곽선을 켜거나 끄도록 개선합니다.

이는 제출 내용의 요약입니다. 샷건 전체 동작이나 완성된 주사 사용 흐름을 검증했다는 뜻은 아닙니다.

## 현재 제작 방향과 후속 작업

아이템 획득과 퍼즐 공통 기반을 별도 작업으로 구분합니다. 퍼즐 기반은 시도·실패·완료와 진행 상태를 공통으로 다루고, 개별 퍼즐에서 각 장치의 조건과 반응을 연결합니다. 문서 읽기와 목표 안내, 설정 화면도 확장합니다. 긴 시네마틱과 음성 대사 제작은 현재 중심 범위에 포함하지 않습니다.
