# 팀 기여

SINGULARITY는 메샤미, 솔마, 푸우가 함께 제작합니다. 이 문서에서는 담당 영역과 실제 반영한 작업을 구분합니다. 확인 기준은 2026년 10월 1일입니다.

| 팀원 | 담당 영역 | 기록 |
| --- | --- | --- |
| 메샤미 | 기획·진행 관리, 플레이어·바디캠·무기, 맵 진행, 저장, 통합과 배포 | [메샤미](meshami.md) |
| 솔마 | 적의 감지·수색·공격, 애니메이션, 벽·천장 이동과 행동 기억 | [솔마](solma.md) |
| 푸우 | 아이템·상호작용, 퍼즐 기반과 개별 퍼즐, 문서 읽기·안내·설정 화면 | [푸우](pooh.md) |

담당 영역에는 후속 제작도 포함됩니다. 팀원의 기능을 연결한 작업에서는 원래 구현 담당과 통합 담당을 함께 기록합니다.

## MVP1 공동 작업

2026년 9월 9일, 메샤미의 플레이어·권총·레벨, 솔마의 AI 전투·애니메이션, 푸우의 HUD·상호작용·열쇠와 문을 하나의 플레이 흐름으로 연결했습니다. 당시 결과와 검증 범위는 [MVP1 기록](../docs/MVP1-2026-09-09.md)에 남겼습니다.

## MVP2 진행 상황

팀 개발본에는 메샤미의 공통 조작·은신·권총과 샷건·문과 상자 조작·침식과 주사 사용, 솔마의 청각 감지, 푸우의 아이템·상태 효과·화면 개선과 구역 진입 퍼즐 기반을 반영했습니다.

최종 무기 애니메이션은 작업 브랜치에서 제작·연결 중입니다. 탄약 획득과 새 총기의 연결, 퍼즐 조건, 실제 맵 배치와 직접 플레이 검사도 남아 있습니다. 전체 상태는 [개발 현황](../docs/DEVELOPMENT.md)을 따릅니다.
