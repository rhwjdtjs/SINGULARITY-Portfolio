# TEAM NIRIZ 개발 기여

SINGULARITY는 메샤미, 솔마님, 푸우님가 공동 제작합니다. 이 문서는 담당 영역과 실제 구현 증거를 연결하는 출발점입니다.

| 팀원 | 주요 담당 | 개발 기록 |
|---|---|---|
| 메샤미 | 기획·진행 관리, 플레이어와 무기, 맵 진행, 저장, 통합과 배포를 담당합니다. | [담당 영역](meshami.md)을 확인합니다. |
| 솔마님 | 두 적의 감지·수색·공격, 애니메이션, 표면 이동과 관찰 기반 학습을 담당합니다. | [담당 영역](solma.md)을 확인합니다. |
| 푸우님 | 아이템·상호작용, 퍼즐 기반과 개별 퍼즐, 문서 읽기·안내·설정 화면을 담당합니다. | [담당 영역](pooh.md)을 확인합니다. |

## MVP1 공동 성과 · 2026년 9월 9일

메샤미의 플레이어·권총·레벨 통합, 솔마님의 AI 전투·애니메이션, 푸우님의 HUD·상호작용·열쇠와 문을 연결하고 팀 통합 테스트를 완료했습니다. [MVP1 기록](../docs/MVP1-2026-09-09.md)에 담당별 구현과 검증 결과를 정리했습니다.

전체 게임의 기능을 한 사람의 성과로 표시하지 않으며, 공동 작업은 설계, 구현, 콘텐츠와 검증의 기여를 나누어 기록합니다.

## 현재 확장 단계 · 2026년 9월 20일

솔마님의 청각 감지 기반은 개발본에 반영했으며, 푸우님의 탄약·상태 효과·외곽선 개선은 검토 중입니다. 전체 구현 상태는 [개발 현황](../docs/DEVELOPMENT.md)에 모아 둡니다.

역할 표는 제작 책임을 설명하며 모든 기능의 완성을 뜻하지 않습니다. 퍼즐 공통 기반은 아이템 획득과 별도 작업으로 구분하고, 공통 조작·애니메이션·화면의 연결은 담당자 간 통합으로 완성합니다.
