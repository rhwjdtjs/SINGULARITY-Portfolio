# TEAM NIRIZ 개발 기여

SINGULARITY는 메샤미, 솔마, 푸우가 공동 제작합니다. 이 문서는 담당 영역과 실제 구현 증거를 연결하는 출발점입니다.

| 팀원 | 주요 담당 | 개발 기록 |
|---|---|---|
| 메샤미 | 플레이어, 전투, 저장, 통합과 빌드 및 배포를 담당합니다. | [담당 영역](meshami.md)을 확인합니다. |
| 솔마 | AI, 추적자, 적 조우와 환경 장치 조우를 담당합니다. | [담당 영역](solma.md)을 확인합니다. |
| 푸우 | 상호작용, 퍼즐, 목표, HUD, 옵션과 자막 및 시네마틱을 담당합니다. | [담당 영역](pooh.md)을 확인합니다. |

공개 구현 사례는 해당 빌드를 검증한 뒤 등록합니다. 전체 게임의 기능을 한 사람의 성과로 표시하지 않으며, 공동 작업은 설계, 구현, 콘텐츠와 검증의 기여를 나누어 기록합니다.
