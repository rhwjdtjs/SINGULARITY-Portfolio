# SINGULARITY

**TEAM NIRIZ가 개발하는 1인칭 바디캠 생존 공포 게임입니다.**

AI가 통제하는 폐병원에서 단서를 수집하고, 제한된 자원으로 위협을 피하며 치료제를 찾아가는 싱글 플레이 게임을 제작하고 있습니다. 바디캠 시점의 탐험, 추적자와의 긴장감, 환경 퍼즐과 서사 진행을 연결합니다.

현재 프로토타입 개발 단계입니다. 이 저장소에서는 게임 소개, 검증한 개발 사례, 팀원별 기여와 공개 배포 이력을 소개합니다. 아래의 게임 구성과 일정은 제작 목표이며, 출시 완료나 성능 검증 결과를 의미하지 않습니다.

| 항목 | 제작 기준 |
|---|---|
| 개발 팀 | TEAM NIRIZ, 3인 팀입니다. |
| 엔진 | Unreal Engine 5.5 계열을 사용합니다. |
| 목표 플랫폼 | Windows PC 및 Steam 출시를 준비합니다. |
| 플레이 방식 | 싱글 플레이와 1인칭 바디캠 시점을 사용합니다. |
| 장르 | 생존 공포, 탐험, 스토리 퍼즐을 결합합니다. |
| 공간 | 일반 병동, 연구실, 지하 터미널을 제작합니다. |
| 목표 분량 | 첫 플레이 기준 2~3시간을 목표로 합니다. |

## 게임 경험

- **탐험과 기록:** 공간의 단서와 목표를 확인하고 다음 구역으로 진행합니다.
- **회피와 생존:** 은신과 이동 경로를 선택하며 추적자와의 거리를 관리합니다.
- **제한된 전투:** 탄약과 소음의 대가를 고려해 사격 여부를 결정합니다.
- **환경 퍼즐:** 공간을 관찰하고 상호작용하여 막힌 동선을 엽니다.
- **바디캠 연출:** 자연스러운 빛, 렌즈 특성, 이동 반응과 공간 음향으로 현장감을 만듭니다.
