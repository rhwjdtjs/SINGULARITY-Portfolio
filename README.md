# SINGULARITY

TEAM NIRIZ가 Unreal Engine 5.5와 C++로 만드는 1인칭 바디캠 생존 공포 게임입니다. 메샤미, 솔마, 푸우 세 명이 함께 개발합니다.

플레이어는 증상을 억제할 약을 찾아 병원을 탐색합니다. 문서와 물건에서 단서를 찾고 퍼즐을 풀어 길을 열며 제한된 탄약과 은신으로 위협에 대응하는 게임을 목표로 합니다.

**2026년 10월 1일 기준, MVP2 기능을 제작·통합 중입니다.** MVP1 기본 플레이 흐름을 통합한 뒤 공통 조작, 은신, 권총·샷건, 문·상자 조작과 침식·주사 사용을 팀 개발본에 반영했습니다. 실제 맵의 배치와 최종 애니메이션 연결, 직접 플레이 검사는 남아 있습니다.

## 제작 방향

| 구분 | 내용 |
| --- | --- |
| 플랫폼 | Windows PC, Steam 출시 준비 |
| 공간 | 1·2층 병원과 3·4·5층 병동을 잇는 5층 구성 |
| 탐색 | 문서 읽기, 물건 관찰, 열쇠와 퍼즐로 통로 개방 |
| 생존 | 약과 주사, 제한된 탄약, 침대·책상 아래 은신 |
| 적 | 총을 사용하지 않는 두 적의 시야·청각 감지와 수색. 벽·천장 이동과 관찰한 행동의 기억은 후속 제작 범위 |
| 사격 | 중앙 조준점과 정밀 조준 확대 없이 총을 살짝 들어 발사하는 방식 |
| 연출 | 문서와 공간 탐색을 중심으로 구성. 적 접근·총성·문 등 판단에 필요한 기본 효과음 유지 |

위 구성에는 제작 예정인 기능이 포함됩니다. 현재 반영한 범위와 남은 작업은 [개발 현황](docs/DEVELOPMENT.md)에 정리했습니다.

역할 표에는 앞으로 제작할 범위도 포함합니다. 각자의 구현과 함께 연결한 부분은 담당별 문서에서 구분합니다.

데모는 **2026년 11월 30일–12월 7일**, 정식 출시는 **2027년 1–6월**을 목표로 합니다. 현재 공개 플레이 빌드는 없습니다. 일정은 검수 결과에 따라 조정하며 다운로드와 실행 안내는 배포할 때 추가합니다.

이 저장소는 공개 소개와 개발 기록을 담습니다. 게임 소스, 구매 에셋과 내부 작업 문서는 포함하지 않으며 이야기의 반전과 퍼즐 정답도 공개하지 않습니다.
